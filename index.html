How I work

Fast, cross-disciplinary, hands-on.

I don't sit neatly in one lane. I've owned game design and narrative, run 30-person productions, built greenlit tools with code, and produced live broadcasts — often on the same résumé line.

The constant is craft: I like taking a fuzzy, still-being-defined problem and shaping it into something people can actually hold, play, and use. Every project here is a quest that shipped.
